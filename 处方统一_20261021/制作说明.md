# 处方统一制作

本轮要求：以已确认的第一张纸本水彩处方笺为基准，补齐其余处方画面，修复拿处方单企鹅嘴边的杂线，并输出完整视频。

## 依据与输入

- 内容依据：`00_原始资料/《海洋“发烧”了》批注版.docx`正文镜头24—25及批注20；本轮用户要求覆盖旧白板处方美术。
- 原片：仓库`demooo/合成版本/目前完整成片/海洋发烧了_目前完整成片.mp4`，709.50秒、17028帧，SHA256 `9fbf054f8d79c58e81fc67633049fd787911f00d664fe46683041bee56d31a77`。
- 用户上传了同名视频；附件超过本执行器32 MiB传输上限，无法下载核对。此次按仓库内同名完整版制作；不能宣称已比较附件字节。
- 原始完整视频保存在本目录`原始完整成片.mp4`，可以恢复。
- 处方章节原始配音及逐句时轴来自`第十一段_适应与减缓`，本轮没有重录台词。成片直接保留原始完整版的AAC音频流。
- 官方监测页面和风电/光伏照片复用原工程真实素材；来源、日期和许可沿用该工程`素材/来源链接.json`及`制作依据与素材来源.md`。页面只展示既有机构/通报日期，不加入预测百分比，不把历史截图当作今日预报。

## 设计与动画

统一为四张独立页面：适应处方、监测预警单、减缓处方、行动选择单。处方纸形、纸纹、深蓝栏、细分栏资料行、R主要诉求、勾选建议、医嘱、签名和分类与第一张一致。减缓与适应分别占一页，最后一张行动单对照两类行动。

企鹅原素材左脸颊下、嘴左侧有两条斜黑线。内置image_gen已修复原角色皮肤、去除这些线及原嘴形，保留原姿势、眼镜、发夹、红领结和透明背景；净面原料仅作动画底图。闭口及三个开口形状为单独绘制的动画图层，不再叠加带底色的旧矩形嘴形补丁。口型由原音轨音量及原台词时窗驱动，停顿闭合，并非逐字音素同步。

角色按前次样片的可见身体高度约369像素制作。气泡采用46号得意黑及公共基线，非末行两端对齐；换行同时平衡各行长度、优先按分句断开，避免短尾行和行首标点。气泡尾尖在角色图层后面，不覆盖额头、眼镜和嘴巴。保留三秒暗场倒计时，之后接原记录与总结。

完整版只替换原始视频第14328—15502帧，即597.000—645.958333秒的处方章节。其它画面按原帧顺序保留，整片重新编码为24fps H.264 Baseline/yuv420p/faststart；音频使用原AAC流。

## 重建

从项目根目录运行：

```bash
python 处方统一_20261021/build_prescriptions.py --render --master --refresh-preview
python 处方统一_20261021/finish_delivery.py
```

脚本需要Pillow、FFmpeg和仓库内原字体、LFS真实媒体文件。只重画静态预览时不加参数。新工程使用随仓库保存的霞鹜文楷绘制左上“开处方”，不依赖Windows专用字体路径；正文继续使用得意黑。`--refresh-preview`同时刷新旧拿板角色原料、适应静态图、三图总览及原五秒处方样片；修复前实际文件已单独保存在本工程，以供恢复。
