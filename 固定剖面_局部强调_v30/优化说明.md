# 厄尔尼诺现象 v30

本版基于v29的16句字幕时间轴，直接复用v28已确认的晓伊配音WAV。保持1920×1080、24fps与原片时长；不拼接其他课程片段，不改封面，不生成新配音。

## 画面与时间轴

全程固定太平洋东西向剖面：左侧印尼、西太平洋；右侧秘鲁、东太平洋。取消整图缩放、横移、回拉与所有橙色圈选。

| 时间 | 核心知识与局部变化 |
| --- | --- |
| 0–5.92秒 | 近海面东风信风，箭头向左；只提高当前箭头的可见度。 |
| 5.92–10.84秒 | 高空回流向右，与低层信风分开标注。 |
| 10.84–16.45秒 | 西侧暖水厚、空气上升、东侧冷水上涌、空气下沉，随原配音逐项引入。 |
| 16.45–17.87秒 | 信风箭头平滑缩短。 |
| 17.87–19.50秒 | 西侧暖层变薄、东侧暖层同时增厚，体现暖水向东扩展。 |
| 19.50–20.81秒 | 东部温跃层继续加深，边界单独高亮；温跃层名称保留于固定安全区域，用细线指向边界。 |
| 20.81–22.68秒 | 冷水上涌箭头变短、变淡。 |
| 22.68–26.96秒 | 中东部暖水层柔和增强色彩，明确念出厄尔尼诺现象。 |
| 26.96–29.30秒 | 云团与对应上升气流水平东移；西侧逐渐出现下沉气流。 |
| 29.30–30.78秒 | 作为一个环流知识组，减弱高空回流与升降气流的可见度。 |
| 30.78–33.73秒 | 先强调东西海温差缩小，再让信风进一步减弱。 |
| 33.73–37.69秒 | 固定概念条总结海洋与大气的正反馈，不再移动镜头或水层。 |

所有位置变化用五次平滑缓动。云团无上下漂移，雨线与云朵同步淡入。科学水层为连续曲面；正常时西深东浅，异常过程逐渐趋平、东部加深。深度是定性示意，不代表实测比例。

标签使用得意黑，固定于独立安全区域，统一文字内边距，最后绘制。标签不会继承对象变换。临时标签淡入淡出；已有基础标签保持位置。底部字幕沿用v29原文和起止时间。

## 检查方式

每帧记录标签外框与文字边界、箭头及云朵包围盒、温跃层边界、字幕边界、对象连续参数、镜头范围、当前主强调组。检查标签与标签、标签与关键对象的避让，以及对象边界和相邻帧位移。仅一个当前主知识点拥有强调状态；其余对象可以进行科学状态所需的连续形态变化。

`检查/逐帧几何检查.jsonl`保留全部帧记录；`检查/质量检查.json`保留结果。另输出12–16秒、19–25秒、28–35秒各12个时间点联系表，以及全片16个关键节点，用于视觉复核。全片解码检查独立于渲染前几何检查。

自动检查覆盖每一帧的几何约束，视觉复核采用指定时段和关键节点的抽帧；不能把两者说成逐帧人工观看。原v29及其工程均保留。
